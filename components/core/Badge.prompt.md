Pill label for statuses and inline metrics, the chips that pepper AgentCory's marketing and dashboards.

```jsx
<Badge tone="success" dot>94% Contact Rate</Badge>
<Badge tone="brand">&lt;5s Answer Time</Badge>
<Badge tone="ink">Voice</Badge>
```

Tones: `brand`, `cyan`, `success`, `warning`, `danger`, `neutral`, `ink`. Sizes `sm` / `md`. Set `dot` for a leading status dot.

Headline metric: AgentCory leads with big numbers everywhere.

```jsx
<StatCard value="<60s" label="Response Time" gradient />
<StatCard value="94%" label="Contact Rate" />
<StatCard value="$2.4M" label="Additional Revenue" sub="reported Year 1" align="center" />
```

`gradient` paints the number blue→cyan (reserve for the hero/primary metric). `align` start or center (start follows reading direction). The value is always isolated LTR so "<60s" never mirrors to ">60s" in Arabic.
